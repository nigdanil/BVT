# Security Policy

## Supported version

Security fixes are accepted for the current BVT release line.

Current public release:

```text
0.1.x
```

## Reporting

Please do not publish credentials, private files or exploit details in
a public issue.

Report a suspected security problem privately to the repository owner
through the available GitHub contact mechanisms.

## Scope

BVT runs locally inside Blender.

The v0.1 release does not require an external account and does not
perform background remote downloads as part of dataset generation.

Users remain responsible for files and third-party assets they import
into Blender.

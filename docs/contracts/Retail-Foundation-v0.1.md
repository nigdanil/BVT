# Retail Foundation v0.1 Contract

Status: Implemented
Milestone: EP3
Reference scene: `beverage_fridge_v01`

---

# 1. Purpose

Retail Foundation defines the first industry-specific reference layer
built on top of BVT core.

It must not modify the frozen Artifact Engine v1 contract.

---

# 2. Architecture Boundary

Retail Foundation owns:

```text
synthetic SKU metadata
package geometry templates
retail scene assets
shelf topology
slot definitions
scene population
deterministic shelf placement
retail asset manifests
retail presets
```

Artifact Engine owns:

```text
image/material artifacts
```

Annotation owns:

```text
class_id
class_name
instance_id
bounding boxes
YOLO labels
```

Dataset generation owns:

```text
images
labels
frame manifest
validation
```

---

# 3. Reference Scene

Canonical EP3 scene:

```text
scene_id = beverage_fridge_v01
```

Scene contains:

```text
fridge carcass
shelves
glass door
product instances
camera
lights
```

Only product instances are annotated as SKU objects.

Fridge structure and shelves are scene infrastructure.

---

# 4. Scene Axes

Canonical retail scene convention:

```text
X = shelf left/right
Y = shelf depth
Z = vertical
```

Shelf front faces:

```text
-Y
```

Product front faces:

```text
-Y
```

---

# 5. Shelf Identity

Stable shelf IDs:

```text
shelf_01
shelf_02
shelf_03
...
```

Shelf IDs are semantic and must not depend on Blender object pointer
values or runtime creation order.

---

# 6. Slot Identity

Every deterministic shelf position has a stable slot ID.

Format:

```text
slot_001
slot_002
slot_003
...
```

A scene placement identity is therefore derived from:

```text
scene_id
shelf_id
slot_id
sku_id
```

---

# 7. Instance Identity

Canonical instance ID:

```text
retail:<scene_id>:<shelf_id>:<slot_id>:<sku_id>
```

This ID must be deterministic.

Retail generation must not rely on the UUID fallback from
`register_object()`.

---

# 8. Geometry Templates

EP3 target:

```text
can
bottle
carton
box
```

Templates must follow `SKU-v0.1.md`:

```text
units = meters
origin = bottom-center
front = -Y
Z = up
```

SKU dimensions scale or parameterize templates.

---

# 9. Beverage Fridge Components

Minimum scene foundation:

```text
fridge body
3 or more shelves
glass door/panel
camera
one or more lights
product placement volume
```

The Glass door material must use:

```text
BVT material role = GLASS
```

This allows the frozen Artifact Engine v1 Glass chain to operate without
Retail-specific artifact code.

---

# 10. Product Annotation

Every product instance maps to existing BVT metadata:

```text
class_id
class_name
instance_id
annotation_enabled = true
registered = true
```

Infrastructure objects remain unregistered for product annotation.

---

# 11. Asset / SKU Manifest

Retail Demo must have a separate source manifest describing scene
composition.

The source manifest is distinct from the generated dataset
`manifest.json`.

Canonical source-manifest responsibilities:

```text
scene_id
SKU pack version
SKU metadata references
shelves
slots
product instances
geometry template references
material/texture references
```

Dataset manifest remains generated by existing BVT export logic.

---

# 12. Placement

Existing BVT random placement offsets are not sufficient to define a
retail planogram.

EP3 introduces deterministic shelf placement as a separate retail
placement layer.

Canonical baseline placement:

```text
SKU
→ shelf
→ slot
→ deterministic transform
```

Random placement may later perturb this baseline, but deterministic
baseline placement must exist first.

---

# 13. Placement Determinism

Same:

```text
scene manifest
SKU pack
project seed
placement configuration
```

must resolve to the same product identities and baseline transforms.

Slot assignment must never depend on:

```text
unordered dict traversal
Blender pointer values
UUID generation
wall-clock time
```

---

# 14. Presets

EP3 prepares at least:

```text
clean
artifacts
```

`clean`:

```text
Artifact Engine disabled
```

`artifacts`:

```text
Artifact Engine enabled
Retail scene and SKU identity unchanged
```

EP6 may later add:

```text
balanced
stress
```

---

# 15. Acceptance Dataset

EP3 exit target:

```text
100 frames
```

Required checks:

```text
100 images
100 YOLO label files
100 frame records
validation PASS
stable class mapping
deterministic instance IDs
valid bboxes
valid GLASS targeting
reproducible generation
```

The acceptance dataset is not the final benchmark dataset.

---

# 16. Scope Gate

EP3 does not implement:

```text
Wrong Angle
Wrong Position
Empty Slot
Occlusion
```

These belong to EP4.

EP3 builds the clean deterministic retail baseline on which those
edge-cases will operate.

---

# 17. Frozen Dependency

Artifact Engine v1 is frozen.

Retail Foundation must consume it through existing public behavior.

EP3 must not add Retail-specific Artifact Engine providers.

---

# 18. Exit Criteria

EP3 is complete when:

- [x] `examples/retail_demo/` exists;
- [x] Beverage Fridge scene exists;
- [x] 3–4 reusable package templates exist;
- [x] initial synthetic SKU pack exists;
- [x] SKU v0.1 contract is implemented;
- [x] asset/SKU manifest exists;
- [x] product objects are registered deterministically;
- [x] shelf placement is deterministic;
- [x] fridge Glass material uses role `GLASS`;
- [x] clean/artifact presets exist;
- [x] 100-frame acceptance dataset passes;
- [x] bbox/YOLO/manifest/validation pass.

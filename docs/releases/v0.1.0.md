# Blender Visual Toolkit v0.1.0

Release date: 2026-11-02

## Summary

v0.1.0 is the first public Blender Visual Toolkit release.

It delivers one complete reference workflow:

```text
Beverage Fridge
→ synthetic SKU pack
→ randomization
→ Artifact Engine
→ retail edge cases
→ YOLO
→ validation
→ productized dataset
```

## Highlights

- Blender UI workflow without Python;
- deterministic generation by seed;
- YOLO bounding boxes;
- eleven Artifact Engine providers;
- four retail edge cases;
- productized dataset layout;
- splits / statistics / health / validation;
- SHA-256 integrity;
- deterministic dataset ZIP;
- public Retail Demo;
- public sample dataset;
- canonical showcase;
- demo video.

## Compatibility

Validated release environment:

```text
Blender 5.2.3 LTS
Windows
```

Linux, macOS and other Blender versions are not part of the v0.1
acceptance matrix.

## Installation

Install:

```text
blender_visual_toolkit-0.1.0.zip
```

through:

```text
Edit → Preferences → Extensions → Install from Disk
```

# BVT SKU Physical Print Pack v0.1

This physical artwork layer uses the exact same eight semantic SKU
identities as the frozen Retail Demo v0.1 dataset.

Source taxonomy:

```text
examples/retail_demo/sku/sku-pack-v0.1.json
```

Physical artwork:

```text
examples/retail_demo/artwork/sku_pack_v0.1/
```

Required physical shapes:

- 2 × 330 ml can-like packages;
- 2 × 500 ml bottle-like packages;
- 2 × 1000 ml carton-like packages;
- 2 × 250 ml box-like packages.

The frozen Retail Demo SKU manifest is not modified by this print pack.

The SVG artwork is a research marker layer for sim-to-real matching.
Final physical print dimensions are defined separately after the proxy
3D models are generated.
